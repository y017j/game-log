# ゲームログ（ログイン・共有版）

プレイしたゲームを記録するWebアプリです。
- IDとパスワードでログイン
- 自分の記録は編集できる／他の人の記録は閲覧のみ
- テーマ切り替え（ダーク / ピンク / ホワイト）

データはブラウザだけでなく、[Supabase](https://supabase.com)（無料）というサービス上に保存されるので、
どの端末からログインしても同じ記録が見られます。

---

## セットアップ手順（最初の1回だけ）

### 1. Supabaseプロジェクトを作る
1. https://supabase.com にアクセスし、無料アカウントを作成
2. 「New project」でプロジェクトを作成（リージョンは Tokyo (ap-northeast-1) がおすすめ）
3. プロジェクトが立ち上がるまで1〜2分待つ

### 2. テーブルを作る
1. 左メニューの「SQL Editor」を開く
2. このフォルダの `supabase-setup.sql` の中身を全部貼り付けて実行（Run）
   - `profiles`（ユーザー名の一覧）と `games`（ゲーム記録）の2つのテーブルができます
   - 「本人のデータしか編集・削除できないが、閲覧はログインしていれば誰でもできる」という設定（RLS）も一緒に入ります

### 3. メール確認を無効にする（重要）
今回は「ID」でログインする作りにしていて、実際のメールアドレスを使わないため、メール確認をOFFにする必要があります。
1. 左メニューの「Authentication」→「Sign In / Providers」→「Email」を開く
2. 「Confirm email」をOFFにして保存

### 4. 接続情報を控える
1. 左メニューの「Project Settings」→「API」を開く
2. 「Project URL」と「anon public」キーをコピー
3. このフォルダの `config.js` を開いて、以下を書き換える
   ```js
   window.SUPABASE_URL = "https://xxxxxxxx.supabase.co";
   window.SUPABASE_ANON_KEY = "ここにanon publicキー";
   ```

### 5. GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成する（例: `game-log`）
   - 無料のGitHub Pagesを使う場合はリポジトリをPublicにする必要があります
2. `index.html` `style.css` `app.js` `config.js` をリポジトリのルートに追加してコミット・プッシュ
   （`supabase-setup.sql` と `README.md` は公開用サイトには不要ですが、一緒に置いておいてもOKです）
3. GitHubのリポジトリ画面で `Settings` → `Pages` を開く
4. 「Build and deployment」の `Source` を `Deploy from a branch` にし、`Branch` を `main` / `/(root)` にして `Save`
5. 数分後 `https://ユーザー名.github.io/リポジトリ名/` でアクセスできます
6. そのURLと、各自が決めたIDでログインする旨を友達に伝えてください（「はじめて使う」から各自アカウント登録）

## 使い方
- 初回は「はじめて使う」タブからID・パスワードを決めて登録
- 2回目以降は「ログイン」タブでログイン
- 画面右上の丸いボタンでテーマ（ダーク／ピンク／ホワイト）を切り替え（自分の端末だけの設定です）
- 「表示するユーザー」から自分以外を選ぶと、その人の記録を閲覧専用で見られます（追加・編集・削除ボタンは自分の記録を見ているときだけ表示されます）
- 「書き出し」で今表示している記録をJSONファイルに保存できます。「読み込み」は自分の記録を見ているときだけ使え、読み込んだ内容は自分の記録として追加されます

## 公開範囲・セキュリティについて（大事な注意）
- GitHub Pages（無料プラン）はリポジトリがPublicである必要があるため、サイトのURLを知っていれば誰でもアクセスできる状態になります。「一般公開しない」を徹底したい場合は、URLを友達以外に教えない、という運用になります
- ログインしている人同士は、お互いの記録を閲覧できる設計です（今回のご要望どおり）。ログインしていない人（未登録の人）はデータを見ることはできません
- `config.js` に入っている「anon public キー」は、Supabaseの仕組み上ブラウザに公開されて問題ないキーです（実際のアクセス制限はSupabase側のRLSポリシーで行っています）。ただし今回の設計はあくまで「友達内の緩い共有」を想定したもので、金融情報など重要なデータの管理には向きません

## テーマを増やしたい・項目を追加したいなど
`style.css` の `html[data-theme="..."]` のブロックを増やせば新しいテーマを追加できます。仕様を変更したい場合は言ってください。

## パッケージ画像（追加機能）
ゲーム追加・編集フォームからパッケージ画像などをアップロードし、一覧カードにも表示できます。

**すでにセットアップ済みの場合にやること（1回だけ）**
1. Supabaseダッシュボード → SQL Editor で `supabase-add-cover-images.sql` の中身を実行
2. `app.js` を最新版に差し替えて、GitHubにコミット・プッシュ

画像は1枚あたり5MBまでです。画像は「covers」という公開バケットに保存され、URLを知っていれば誰でも閲覧できる形式になります（アップロード・削除は本人のみ可能）。編集画面の「画像を削除」リンクで、登録済みの画像を外すこともできます。

## 今回の追加機能（アイコン・年・グループなど）

**まずSupabaseで実行すること（1回だけ）**
1. SQL Editorで `supabase-add-groups-and-profile.sql` の中身を実行
2. `app.js` / `style.css` / `index.html` の3ファイルを最新版に差し替えてGitHubへコミット・プッシュ

**変更内容**
- **アイコン**: 画面右上の丸いボタンから、自分の顔アイコン的な画像をアップロードできます（丸形表示）
- **記録日 → 自動表示に変更**: 手入力の「記録日」は廃止し、代わりにカードの右上に「更新日時」が自動で小さく表示されます
- **プレイしていた年**: 「2008年」のように、実際にプレイしていた年を記録できます。並び替えにも「プレイ年が新しい順」を追加しました
- **プラットフォームの候補表示**: 一度使ったプラットフォーム名（Switch、PS5など）は、次回の入力時に候補として選べるようになります（自分の記録から集計されます）
- **テーマがアカウントに保存される**: テーマ設定はSupabase側のプロフィールにも保存されるため、別の端末でログインしても同じテーマになります
- **グループ機能**: 「グループ管理」ボタンから、友達だけの閉じたグループを作成できます
  - グループを作ると、そのグループのメンバー同士だけが「表示するユーザー」に表示され、お互いのゲームログを閲覧できます
  - 招待はユーザーIDを入力するだけです（現状は入力したら即メンバーに追加される仕様です。承認制にしたい場合は言ってください）
  - どのグループにも入っていない人からは、あなたの記録は見えません
  - オーナー（作成者）はメンバーを削除でき、メンバー自身はいつでもグループを抜けられます

**注意**: ユーザー名（ID）自体は、招待のために検索できるよう、ログインしている人なら誰でも見える状態のままです（アバター画像も同様）。非公開になるのは「ゲームの記録内容」で、グループ外の人からは見えません。

## 自己紹介・並び替え強化・積みゲーの入力制限（追加分）

**Supabaseで実行すること（1回だけ）**
1. SQL Editorで `supabase-add-bio.sql` を実行
2. `app.js` / `style.css` / `index.html` を最新版に差し替えてGitHubへコミット・プッシュ

**変更内容**
- **自己紹介**: 「プロフィール設定」（アイコンボタン）から自己紹介文（200文字まで）を設定できます
- **相手のアイコン＋自己紹介の吹き出し**: 「表示するユーザー」を切り替えると、そのユーザーのアイコンと自己紹介が吹き出し形式で表示されます
- **積みゲーの入力制限**: ステータスを「積みゲー」にすると、評価とプレイ時間の入力欄がグレーアウトして入力できなくなります（切り替えると自動でクリアされます）
- **プレイ時間順の並び替え**を追加
- **すべての並び替えに逆順を追加**（新しい順⇔古い順、高い順⇔低い順、長い順⇔短い順、あ→ん⇔ん→あ、など）
